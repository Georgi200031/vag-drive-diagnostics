# VAG Drive Diagnostics — privacy page

Static privacy-policy page for the VAG Drive Diagnostics mobile application.

## Contents

privacy.html is the published policy document. This repository does not contain the Android app source or diagnostic engine.

Preview the HTML directly in a browser, or serve it with any static web server. If using GitHub Pages, keep the existing privacy.html URL stable because app-store listings may refer to it.

Changes to policy claims must reflect the actual app and services. Documentation cleanup does not independently verify those claims or change the app's data handling.

## Maintenance

Preserve the existing source and sample assets when making changes. Do not commit credentials, personal data or generated build output. This review documents the checked-in project; it does not certify production readiness or a successful build on every platform.
